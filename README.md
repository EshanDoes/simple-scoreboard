# Simple Scoreboard

This was originally meant to be a simple Next.js web app to track scores of contestants when trying to achieve a goal. However, I got preoccupied with another project I was much more interested in, so this ended up getting scrapped. The website is still available on the repository, but it's not really functional.

## What is and isn't done


- [x] Primary styling (although it's not the best in my opinion)
- [x] Using dictionaries to display scoreboard
- [ ] Editing scoreboard
- [ ] Importing/exporting scoreboard
- [ ] Adding/subtracting score to scoreboard

## Getting Started

#### Prerequisites:
- Node.js
- npm

#### Installation:
```bash
# Step 1: Clone repository
git clone https://github.com/EshanDoes/simple-scoreboard

# Step 2: Open project
cd simple-scoreboard

# Step 3: Install dependencies
npm install next@latest react@latest react-dom@latest tailwindcss @tailwindcss/postcss postcss

# Step 4: Run dev server
npm run dev
```

#### Production build:
```bash
npm run build
```
